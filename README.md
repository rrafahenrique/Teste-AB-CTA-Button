# Introdução
Este projeto, tem como objetivo realizar um Teste A/B utilizando dados ficticios de uma empresa que oferece cursos, bootcamps e suporte de carreira para ajudar ajudar alunos a conquistarem um vaga na área de dados.

O teste A/B é um método estatístico amplamente utilizado para comparar duas versões de uma variável. Neste caso, o objetivo foi identificar qual versão do botão de chamada para ação (CTA) na página inicial da empresa apresenta um desempenho superior, com base na métrica de taxa de cliques (CTR, na sigla em inglês):

- **Grupo de Controle:** Exposto ao botão de CTA atual ("Garantir teste gratuito").
- **Grupo Experimental:** Exposto ao novo botão de CTA, de caráter mais geral ("Inscreva-se agora").

![banner](img/banner.png)


A taxa de cliques (CTR) mede a porcentagem de usuários que clicam em um botão ou link após visualizá-lo. Para a empresa, o CTR é importante, pois reflete o engajamento dos usuários com a plataforma e auxilia na avaliação da eficácia dos botões de chamada para ação em gerar inscrições e conversões.

Por fim, os resultados deste teste ajudarão a decidir se o novo botão deve ser implementado na página inicial.
